## いま取り組んでいること

### LandingHub

[**LandingHub**](https://www.landinghub.net/) は、Web ページや LP の表示速度を改善する SaaS です。
サイトにタグを 1 行追加するだけで、画像・動画の圧縮、次世代フォーマットへの変換、CDN 最適化などを自動で行い、
表示速度・CVR・SEO の改善を支援します。Core Web Vitals（LCP / INP / CLS）の最適化にも対応しています。

- 無料の表示速度診断: https://www.landinghub.net/diagnosis
